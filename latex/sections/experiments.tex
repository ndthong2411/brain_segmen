\section{Experiments and Results}

\subsection{Dataset and Preprocessing}

\subsubsection{BraTS 2020 Dataset}

We evaluate our method on the Brain Tumor Segmentation (BraTS) 2020 Challenge dataset \cite{menze2015brats,bakas2018brats}. The dataset comprises 369 multi-modal MRI scans of glioma patients, with 293 high-grade gliomas (HGG) and 76 low-grade gliomas (LGG). Each case includes four MRI modalities:
\begin{itemize}
\item \textbf{FLAIR} (Fluid Attenuated Inversion Recovery): Highlights edema regions
\item \textbf{T1}: Native T1-weighted imaging showing anatomical structure
\item \textbf{T1CE}: T1-weighted with contrast enhancement, highlighting active tumor
\item \textbf{T2}: T2-weighted imaging sensitive to water content
\end{itemize}

All images are skull-stripped, co-registered to the same anatomical template, and resampled to $1 \text{mm}^3$ isotropic resolution with size $240 \times 240 \times 155$ voxels.

Ground truth annotations provide voxel-wise labels for four tumor sub-regions:
\begin{itemize}
\item Label 0: Background (healthy tissue)
\item Label 1: Necrotic and non-enhancing tumor core (NCR/NET)
\item Label 2: Peritumoral edema (ED)
\item Label 4: GD-enhancing tumor (ET)
\end{itemize}

\subsubsection{Label Conversion for 3-Class Segmentation}

Following the BraTS evaluation protocol, we convert the original 4-label annotations to 3-class segmentation:
\begin{align}
\text{Class 0} &: \text{Background} = \{\text{Label 0}\} \\
\text{Class 1} &: \text{Tumor Core (TC)} = \{\text{Label 1, Label 4}\} = \text{NCR} \cup \text{ET} \\
\text{Class 2} &: \text{Edema (ED)} = \{\text{Label 2}\}
\end{align}

The evaluation regions are defined as:
\begin{align}
\text{Whole Tumor (WT)} &= \text{TC} \cup \text{ED} = \{\text{Class 1, Class 2}\} \\
\text{Tumor Core (TC)} &= \{\text{Class 1}\} \\
\text{Enhancing Tumor (ET)} &= \text{Not evaluated in 3-class setting}
\end{align}

\subsubsection{Preprocessing Pipeline}

Our preprocessing consists of the following steps:

\textbf{Step 1: Intensity Normalization.} Each modality is independently normalized using z-score normalization within the brain mask:
\begin{equation}
\hat{x}_{ij} = \frac{x_{ij} - \mu_i}{\sigma_i + \epsilon}
\end{equation}
where $x_{ij}$ is the intensity of modality $i$ at voxel $j$, $\mu_i$ and $\sigma_i$ are mean and standard deviation computed only over non-zero voxels (brain tissue), and $\epsilon=10^{-8}$ prevents division by zero.

\textbf{Step 2: Slice Extraction.} From each 3D volume, we extract 2D axial slices. To balance computational efficiency with data coverage, we sample 20 slices per case using a tumor-enriched strategy:
\begin{itemize}
\item 50\% of slices are randomly sampled from tumor-containing slices
\item 50\% are randomly sampled from all slices (including background-only)
\end{itemize}
This balancing prevents the model from over-fitting to tumor-heavy regions while maintaining sufficient tumor examples.

\textbf{Step 3: Resizing.} All slices are resized from $240 \times 240$ to $256 \times 256$ pixels using bilinear interpolation for images and nearest-neighbor interpolation for masks (to preserve integer class labels).

\textbf{Step 4: Data Split.} We employ stratified 5-fold cross-validation, ensuring balanced distribution of HGG/LGG cases across folds. Each fold uses approximately:
\begin{itemize}
\item Training: 295 cases ($\sim$18,140 slices)
\item Validation: 74 cases ($\sim$4,537 slices)
\end{itemize}

\subsection{Implementation Details}

\subsubsection{Model Configurations}

We experiment with three model variants:

\textbf{Baseline V1 (14M parameters):}
\begin{itemize}
\item Base channels: 32
\item Transformer dimension: 256
\item Transformer depth: 2 layers
\item Attention heads: 4
\item Dropout: 0.0
\item Multi-scale fusion: Disabled
\end{itemize}

\textbf{Phase 2 Small (37M parameters):}
\begin{itemize}
\item Base channels: 48
\item Transformer dimension: 384
\item Transformer depth: 4 layers
\item Attention heads: 8
\item Dropout: 0.15
\item Multi-scale fusion: Enabled
\end{itemize}

\textbf{Phase 2 Large (87M parameters):}
\begin{itemize}
\item Base channels: 64
\item Transformer dimension: 512
\item Transformer depth: 4 layers
\item Attention heads: 8
\item Dropout: 0.2
\item Multi-scale fusion: Enabled
\end{itemize}

\subsubsection{Training Configuration}

All models are trained for 400 epochs with early stopping (patience 30 epochs) using the following configuration:
\begin{itemize}
\item Optimizer: AdamW with $\beta_1=0.9$, $\beta_2=0.999$
\item Learning rate: $5 \times 10^{-5}$ (large), $3 \times 10^{-5}$ (small)
\item Weight decay: $1.5 \times 10^{-4}$
\item Batch size: 16 (A100 80GB), 12 (RTX 3090 24GB)
\item Mixed precision: BFloat16 (A100) or Float16 (RTX 3090)
\item Gradient clipping: max norm 1.0
\item Learning rate schedule: Cosine annealing with warm-up (2000 steps for large, 1000 for small)
\end{itemize}

Loss function weights:
\begin{itemize}
\item Segmentation weight: $w_{\text{seg}}=1.0$
\item Classification weight: $w_{\text{cls}}=0.5$
\item Dice weight: $w_D=1.0$
\item Focal weight: $w_F=1.0$, $\gamma=3.0$, $\alpha=[0.0, 0.4, 0.3]$
\item IoU weight: $w_I=2.5$
\item Boundary weight: $w_B=0.6$
\item Deep supervision weight: $w_{\text{aux}}=0.3$
\item Class weights: $[1.0, 3.0, 4.0]$ for [BG, TC, ED]
\end{itemize}

\subsection{Evaluation Metrics}

Following the BraTS evaluation protocol, we report three primary metrics:

\textbf{Dice Similarity Coefficient (DSC):}
\begin{equation}
\text{DSC} = \frac{2|P \cap G|}{|P| + |G|}
\end{equation}
where $P$ is the predicted segmentation and $G$ is the ground truth for each region (WT, TC, ED).

\textbf{Intersection over Union (IoU):}
\begin{equation}
\text{IoU} = \frac{|P \cap G|}{|P \cup G|}
\end{equation}

\textbf{Hausdorff Distance 95th Percentile (HD95):}
\begin{equation}
\text{HD95}(P, G) = \max(h_{95}(P, G), h_{95}(G, P))
\end{equation}
where $h_{95}(A, B)$ is the 95th percentile of distances from points in $A$ to the nearest point in $B$.

For classification, we report accuracy, F1-score, and AUC-ROC for HGG vs LGG prediction.

\subsection{Limitations}

Current limitations of BrainTumNetV2:
\begin{itemize}
\item \textbf{2D processing:} We process 2D slices independently, losing 3D context. Future work should extend to 3D volumes.
\item \textbf{Computational cost:} The large variant requires 80GB VRAM, limiting deployment. Model compression techniques could address this.
\item \textbf{Single dataset:} We evaluate only on BraTS 2020. Generalization to other datasets needs validation.
\item \textbf{Manual hyperparameter tuning:} Loss weights and architecture choices are manually tuned. Automated search could improve this.
\end{itemize}

\begin{abstract}
Brain tumor segmentation and classification from multi-modal MRI scans remain challenging tasks in medical image analysis due to high variability in tumor appearance, irregular boundaries, and severe class imbalance. We present AMT-UNet (Adaptive Masked Transformer U-Net), a hybrid CNN-transformer architecture for simultaneous 3-class tumor segmentation and binary grade classification. Our method features a residual encoder-decoder with instance normalization, an adaptive masked transformer bottleneck that focuses computation on tumor-relevant regions through learned soft masking, CBAM attention mechanisms on skip connections, and multi-scale feature fusion across all decoder levels. We introduce a combined loss function integrating Dice, focal, IoU, and boundary losses with deep supervision to optimize multiple complementary objectives. The multi-task framework employs ROI-guided classification where predicted tumor regions gate the classification input with gradient stopping to prevent task interference. Experiments on the BraTS 2020 dataset demonstrate that AMT-UNet achieves competitive performance with 37M parameters and efficient inference.

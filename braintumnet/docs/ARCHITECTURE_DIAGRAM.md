## Overall System Architecture

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                          BrainTumNetV2 Complete Pipeline                        │
└─────────────────────────────────────────────────────────────────────────────────┘

Input: Multi-modal MRI (FLAIR, T1, T1CE, T2)
Shape: (B, 4, 256, 256)
          │
          ├───────────────────────────────────────────────────────────┐
          │                                                           │
          │  ┌────────────────────────────────────────────┐          │
          │  │     SEGMENTATION BRANCH (SegUNetV2)        │          │
          │  │                                             │          │
          │  │  ┌──────────────────────────────────────┐  │          │
          │  │  │         ENCODER (CNN)                │  │          │
          │  │  │                                       │  │          │
          │  │  │  E1: 256×256×4    →  128×128×48     │  │    Skip connections
          │  │  │  E2: 128×128×48   →   64×64×96      │  │  ────────────────┐
          │  │  │  E3:  64×64×96    →   32×32×192     │  │  ────────────┐   │
          │  │  │  E4:  32×32×192   →   16×16×384     │  │  ────────┐   │   │
          │  │  │      (Residual, LeakyReLU, InstanceNorm) │          │   │   │
          │  │  └──────────────────┬───────────────────┘  │          │   │   │
          │  │                     │                        │          │   │   │
          │  │  ┌──────────────────▼───────────────────┐  │          │   │   │
          │  │  │  BOTTLENECK (Adaptive Masked Transformer) │          │   │   │
          │  │  │                                       │  │          │   │   │
          │  │  │  16×16×384 → 256 patches (8×8 each)│  │          │   │   │
          │  │  │  Self-Attention with dynamic masking│  │          │   │   │
          │  │  │  Depth=4, Heads=8, Dim=512         │  │          │   │   │
          │  │  └──────────────────┬───────────────────┘  │          │   │   │
          │  │                     │                        │          │   │   │
          │  │  ┌──────────────────▼───────────────────┐  │          │   │   │
          │  │  │         DECODER (CNN + CBAM)         │  │          │   │   │
          │  │  │                                       │  │          │   │   │
          │  │  │  D4: 16×16×384   →   32×32×384  ◄────┼──┼──────────┘   │   │
          │  │  │  D3: 32×32×384   →   64×64×192  ◄────┼──┼──────────────┘   │
          │  │  │  D2: 64×64×192   →  128×128×96  ◄────┼──┼──────────────────┘
          │  │  │  D1: 128×128×96  →  256×256×48  ◄────┼──┘
          │  │  │      (CBAM attention on skip connections)
          │  │  └──────────────────┬───────────────────┘  │
          │  │                     │                        │
          │  │  ┌──────────────────▼───────────────────┐  │
          │  │  │   MULTI-SCALE FUSION                 │  │
          │  │  │   Combine [D1, D2↑, D3↑, D4↑]       │  │
          │  │  │   All upsampled to 256×256           │  │
          │  │  └──────────────────┬───────────────────┘  │
          │  │                     │                        │
          │  │  ┌──────────────────▼───────────────────┐  │
          │  │  │   DEEP SUPERVISION                   │  │
          │  │  │                                       │  │
          │  │  │   Main:  (B, 3, 256, 256)           │  │
          │  │  │   Aux1:  (B, 3, 256, 256)           │  │
          │  │  │   Aux2:  (B, 3, 128, 128)           │  │
          │  │  │   Aux3:  (B, 3,  64,  64)           │  │
          │  │  └──────────────────┬───────────────────┘  │
          │  └─────────────────────┼──────────────────────┘
          │                        │
          │                  Segmentation Output
          │                  Shape: (B, 3, 256, 256)
          │                  Classes: [Background, TC, ED]
          │                        │
          │                        ├─────── To Loss
          │                        │
          │                        └─────── ROI Gating ────┐
          │                                                 │
          │  ┌──────────────────────────────────────────── │ ────┐
          │  │     CLASSIFICATION BRANCH (T-InceptionNet)   │     │
          │  │                                              │     │
          │  │  ┌────────────────────────────────────────┐ │     │
          │  │  │  ROI GATING                            │ │     │
          │  │  │                                         │ │     │
          │  │  │  1. Softmax(seg_logits) → probs       │ │     │
          │  │  │  2. WT_prob = TC_prob + ED_prob        │ │     │
          │  │  │  3. roi_input = Reduce(input)          │ │     │
          │  │  │  4. roi = roi_input * WT_prob.detach() │ │     │
          │  │  │     Shape: (B, 1, 256, 256)            │ │     │
          │  │  └────────────────┬───────────────────────┘ │     │
          │  │                   │                          │     │
          │  │  ┌────────────────▼───────────────────────┐ │     │
          │  │  │  T-INCEPTION BLOCKS                    │ │     │
          │  │  │                                         │ │     │
          │  │  │  Multi-scale convolutions:             │ │     │
          │  │  │  - 1×1, 3×3, 1×3, 3×1 in parallel      │ │     │
          │  │  │  - Concatenate outputs                 │ │     │
          │  │  │  - Repeated 3-4 times                  │ │     │
          │  │  └────────────────┬───────────────────────┘ │     │
          │  │                   │                          │     │
          │  │  ┌────────────────▼───────────────────────┐ │     │
          │  │  │  CLASSIFICATION HEAD                   │ │     │
          │  │  │                                         │ │     │
          │  │  │  GlobalAvgPool → FC(512) → Dropout →   │ │     │
          │  │  │  FC(num_classes=2)                     │ │     │
          │  │  │                                         │ │     │
          │  │  │  Output: (B, 2) logits [HGG, LGG]      │ │     │
          │  │  └─────────────────────────────────────────┘ │     │
          │  └─────────────────────────────────────────────────────┘
          │                        │
          │                 Classification Output
          │                 Shape: (B, 2)
          │                        │
          ▼                        ▼
    ┌─────────────────────────────────────┐
    │       ULTIMATE MULTI-TASK LOSS       │
    │                                      │
    │  Segmentation:                       │
    │    - Dice Loss                       │
    │    - Focal Loss (alpha=[0,0.4,0.3])  │
    │    - IoU Loss (weights=[1,3,4])      │
    │    - Boundary Loss                   │
    │    - Deep Supervision (3 aux)        │
    │                                      │
    │  Classification:                     │
    │    - CrossEntropy Loss               │
    │                                      │
    │  Total = seg_w × (main + aux_w×aux)  │
    │          + cls_w × cls               │
    └──────────────────────────────────────┘
```

## SegUNetV2 Detailed Architecture

```
┌───────────────────────────────────────────────────────────────────────────────┐
│                         SegUNetV2: Enhanced U-Net                              │
│                   Phase 2 with InstanceNorm, LeakyReLU, Residual              │
└───────────────────────────────────────────────────────────────────────────────┘

Input Image: (B, 4, 256, 256)  [FLAIR, T1, T1CE, T2]
      │
      ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│  ENCODER STAGE 1                                                             │
│  ┌────────────────────────────────────────────────────────────────────────┐  │
│  │  ResidualConvBlock(in=4, out=48)                                       │  │
│  │                                                                         │  │
│  │  ┌─────────────────────────────────────────────────────────────────┐  │  │
│  │  │  Conv3×3(4→48) + InstanceNorm + LeakyReLU + Dropout(0.0)        │  │  │
│  │  │  Conv3×3(48→48) + InstanceNorm                                   │  │  │
│  │  │  Residual: Conv1×1(4→48) if channels mismatch                   │  │  │
│  │  │  Add + LeakyReLU                                                 │  │  │
│  │  └─────────────────────────────────────────────────────────────────┘  │  │
│  │  Output: skip1 = (B, 48, 256, 256)                                     │  │
│  │                                                                         │  │
│  │  Downsample: Conv3×3(stride=2)                                         │  │
│  │  Output: (B, 48, 128, 128) ──────────────────────────────────────────────┐
│  └────────────────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────────────┘
                                                                                 │
┌────────────────────────────────────────────────────────────────────────────┐ │
│  ENCODER STAGE 2                                                           │ │
│  ┌──────────────────────────────────────────────────────────────────────┐ │ │
│  │  ResidualConvBlock(in=48, out=96)                                    │ │ │
│  │  Output: skip2 = (B, 96, 128, 128)                                   │ │ │
│  │  Downsample: (B, 96, 64, 64) ─────────────────────────────────────────┼─┼─┐
│  └──────────────────────────────────────────────────────────────────────┘ │ │ │
└────────────────────────────────────────────────────────────────────────────┘ │ │
                                                                                │ │
┌────────────────────────────────────────────────────────────────────────────┐ │ │
│  ENCODER STAGE 3                                                           │ │ │
│  ┌──────────────────────────────────────────────────────────────────────┐ │ │ │
│  │  ResidualConvBlock(in=96, out=192)    Dropout(0.15)                  │ │ │ │
│  │  Output: skip3 = (B, 192, 64, 64)                                    │ │ │ │
│  │  Downsample: (B, 192, 32, 32) ─────────────────────────────────────────┼─┼─┼─┐
│  └──────────────────────────────────────────────────────────────────────┘ │ │ │ │
└────────────────────────────────────────────────────────────────────────────┘ │ │ │
                                                                                │ │ │
┌────────────────────────────────────────────────────────────────────────────┐ │ │ │
│  ENCODER STAGE 4                                                           │ │ │ │
│  ┌──────────────────────────────────────────────────────────────────────┐ │ │ │ │
│  │  ResidualConvBlock(in=192, out=384)   Dropout(0.15)                  │ │ │ │ │
│  │  Output: skip4 = (B, 384, 32, 32)                                    │ │ │ │ │
│  │  Downsample: (B, 384, 16, 16)                                        │ │ │ │ │
│  └──────────────────┬───────────────────────────────────────────────────┘ │ │ │ │
└─────────────────────┼──────────────────────────────────────────────────────┘ │ │ │
                      │                                                         │ │ │
                      ▼                                                         │ │ │
┌──────────────────────────────────────────────────────────────────────────────┐│ │
│  BOTTLENECK: Adaptive Masked Transformer                                     ││ │
│  ┌────────────────────────────────────────────────────────────────────────┐ ││ │
│  │  Conv1×1: 384 → 512 (bottleneck_conv)                                  │ ││ │
│  │  Shape: (B, 512, 16, 16)                                               │ ││ │
│  │                                                                         │ ││ │
│  │  ┌───────────────────────────────────────────────────────────────────┐│ ││ │
│  │  │  Adaptive Masked Transformer (AMT)                                ││ ││ │
│  │  │                                                                    ││ ││ │
│  │  │  1. Patch Embedding: 16×16 → 256 patches of 8×8                  ││ ││ │
│  │  │     Shape: (B, 256, 512)                                          ││ ││ │
│  │  │                                                                    ││ ││ │
│  │  │  2. Transformer Encoder × 4 layers:                               ││ ││ │
│  │  │     ┌─────────────────────────────────────────────────────────┐  ││ ││ │
│  │  │     │  Multi-Head Self-Attention (8 heads)                    │  ││ ││ │
│  │  │     │  - Q, K, V projections: (B, 256, 512) → (B, 256, 8, 64) │  ││ ││ │
│  │  │     │  - Attention weights with adaptive masking              │  ││ ││ │
│  │  │     │  - Output: (B, 256, 512)                                 │  ││ ││ │
│  │  │     ├─────────────────────────────────────────────────────────┤  ││ ││ │
│  │  │     │  Layer Norm + Residual                                   │  ││ ││ │
│  │  │     ├─────────────────────────────────────────────────────────┤  ││ ││ │
│  │  │     │  MLP (512 → 2048 → 512)                                  │  ││ ││ │
│  │  │     ├─────────────────────────────────────────────────────────┤  ││ ││ │
│  │  │     │  Layer Norm + Residual                                   │  ││ ││ │
│  │  │     └─────────────────────────────────────────────────────────┘  ││ ││ │
│  │  │                                                                    ││ ││ │
│  │  │  3. Reshape back: (B, 256, 512) → (B, 512, 16, 16)               ││ ││ │
│  │  └───────────────────────────────────────────────────────────────────┘│ ││ │
│  │                                                                         │ ││ │
│  │  TransposedConv: 512 → 384 (kernel=8×8, stride=8)                     │ ││ │
│  │  Shape: (B, 384, 16, 16)                                               │ ││ │
│  └──────────────────┬──────────────────────────────────────────────────────┘ ││ │
└─────────────────────┼────────────────────────────────────────────────────────┘│ │
                      │                                                          │ │
                      ▼                                                          │ │
┌──────────────────────────────────────────────────────────────────────────────┐│ │
│  DECODER STAGE 4                                                             ││ │
│  ┌────────────────────────────────────────────────────────────────────────┐ ││ │
│  │  Upsample: TransposeConv2d(384→384, kernel=2, stride=2)                │ ││ │
│  │  Output: (B, 384, 32, 32)                                              │ ││ │
│  │                                                                         │ ││ │
│  │  Skip Connection: skip4 = (B, 384, 32, 32) ◄────────────────────────────┼─┘
│  │  CBAM Attention on skip4                                                │ │
│  │                                                                         │ │
│  │  Concatenate: [upsampled, skip4_cbam] → (B, 768, 32, 32)               │ │
│  │  ResidualConvBlock(768→384)  Dropout(0.15)                             │ │
│  │  Output: d4 = (B, 384, 32, 32)                                         │ │
│  │  ┌──────────────────────────────────────────────────────────────────┐ │ │
│  │  │  AUX HEAD 3: Conv1×1(384→3)                                       │ │ │
│  │  │  Output: aux3 = (B, 3, 32, 32)  [for deep supervision]            │ │ │
│  │  └──────────────────────────────────────────────────────────────────┘ │ │
│  └──────────────────┬───────────────────────────────────────────────────────┘ │
└─────────────────────┼──────────────────────────────────────────────────────────┘
                      │
                      ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│  DECODER STAGE 3                                                             │
│  Upsample → (B, 192, 64, 64)                                                 │
│  Concat with skip3 (CBAM) → (B, 384, 64, 64)                                 │
│  ResidualConvBlock(384→192)  Dropout(0.15)                                   │
│  Output: d3 = (B, 192, 64, 64)                                               │
│  AUX HEAD 2: aux2 = (B, 3, 64, 64)                                           │
└──────────────────────┬───────────────────────────────────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│  DECODER STAGE 2                                                             │
│  Upsample → (B, 96, 128, 128)                                                │
│  Concat with skip2 (CBAM) → (B, 192, 128, 128)                               │
│  ResidualConvBlock(192→96)  Dropout(0.075)                                   │
│  Output: d2 = (B, 96, 128, 128)                                              │
│  AUX HEAD 1: aux1 = (B, 3, 128, 128)                                         │
└──────────────────────┬───────────────────────────────────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│  DECODER STAGE 1                                                             │
│  Upsample → (B, 48, 256, 256)                                                │
│  Concat with skip1 (CBAM) → (B, 96, 256, 256)                                │
│  ResidualConvBlock(96→48)  Dropout(0.0)                                      │
│  Output: d1 = (B, 48, 256, 256)                                              │
└──────────────────────┬───────────────────────────────────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│  MULTI-SCALE FUSION (Optional)                                               │
│  ┌────────────────────────────────────────────────────────────────────────┐ │
│  │  Inputs: [d1@256, d2@128, d3@64, d4@32]                                │ │
│  │                                                                         │ │
│  │  1. Project each to same channels (48):                                │ │
│  │     d1_proj = Conv1×1(48→48)   → (B, 48, 256, 256)                     │ │
│  │     d2_proj = Conv1×1(96→48)   → (B, 48, 128, 128)                     │ │
│  │     d3_proj = Conv1×1(192→48)  → (B, 48, 64, 64)                       │ │
│  │     d4_proj = Conv1×1(384→48)  → (B, 48, 32, 32)                       │ │
│  │                                                                         │ │
│  │  2. Upsample all to 256×256:                                           │ │
│  │     d2_up = Interpolate(d2_proj, size=256) → (B, 48, 256, 256)         │ │
│  │     d3_up = Interpolate(d3_proj, size=256) → (B, 48, 256, 256)         │ │
│  │     d4_up = Interpolate(d4_proj, size=256) → (B, 48, 256, 256)         │ │
│  │                                                                         │ │
│  │  3. Fuse by summation:                                                 │ │
│  │     fused = d1_proj + d2_up + d3_up + d4_up                            │ │
│  │     fused = InstanceNorm(fused) + LeakyReLU                            │ │
│  │     Shape: (B, 48, 256, 256)                                           │ │
│  │                                                                         │ │
│  │  4. Combine with final decoder:                                        │ │
│  │     combined = Concat[d1, fused] → (B, 96, 256, 256)                   │ │
│  │     final = ResidualConvBlock(96→48) → (B, 48, 256, 256)               │ │
│  └────────────────────────────────────────────────────────────────────────┘ │
└──────────────────────┬───────────────────────────────────────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│  SEGMENTATION HEAD                                                           │
│  Conv1×1(48→3)                                                               │
│  Output: seg_main = (B, 3, 256, 256)  [Background, TC, ED]                   │
└──────────────────────────────────────────────────────────────────────────────┘

Final Outputs:
  - seg_main: (B, 3, 256, 256)  ← Main segmentation
  - aux1: (B, 3, 256, 256)      ← Deep supervision level 1
  - aux2: (B, 3, 128, 128)      ← Deep supervision level 2
  - aux3: (B, 3, 64, 64)        ← Deep supervision level 3
```

## Encoder Block Details

```
┌──────────────────────────────────────────────────────────────────────┐
│  ResidualConvBlock (Enhanced with InstanceNorm + LeakyReLU)         │
│                                                                      │
│  Input: x (B, in_ch, H, W)                                          │
│                                                                      │
│  ┌────────────────────────────────────────────────────────────────┐│
│  │  Main Path:                                                     ││
│  │  ┌──────────────────────────────────────────────────────────┐ ││
│  │  │  Conv3×3(in_ch → out_ch, padding=1, bias=False)          │ ││
│  │  │  InstanceNorm2d(out_ch, affine=True)                     │ ││
│  │  │  LeakyReLU(negative_slope=0.01)                          │ ││
│  │  │  Dropout2d(p=dropout) [if dropout > 0]                   │ ││
│  │  └──────────────────────────────────────────────────────────┘ ││
│  │                           │                                     ││
│  │  ┌──────────────────────────────────────────────────────────┐ ││
│  │  │  Conv3×3(out_ch → out_ch, padding=1, bias=False)         │ ││
│  │  │  InstanceNorm2d(out_ch, affine=True)                     │ ││
│  │  └──────────────────────────────────────────────────────────┘ ││
│  │                           │                                     ││
│  └───────────────────────────┼─────────────────────────────────────┘│
│                              │                                      │
│  ┌───────────────────────────────────────────────────────────────┐ │
│  │  Residual Path (if in_ch ≠ out_ch):                          │ │
│  │  Conv1×1(in_ch → out_ch, bias=False)                         │ │
│  │  else: Identity                                               │ │
│  └───────────────────────────────────────────────────────────────┘ │
│                              │                                      │
│  ┌───────────────────────────▼─────────────────────────────────┐  │
│  │  Add (main_path + residual_path)                            │  │
│  │  LeakyReLU(negative_slope=0.01)                             │  │
│  └─────────────────────────────────────────────────────────────┘  │
│                              │                                      │
│  Output: (B, out_ch, H, W)                                          │
└──────────────────────────────────────────────────────────────────────┘


┌──────────────────────────────────────────────────────────────────────┐
│  EncoderBlock = ResidualConvBlock + Strided Downsampling            │
│                                                                      │
│  Input: x (B, in_ch, H, W)                                          │
│                                                                      │
│  ┌────────────────────────────────────────────────────────────────┐│
│  │  features = ResidualConvBlock(in_ch, out_ch)                   ││
│  │  Shape: (B, out_ch, H, W) ──────────────────── Skip Connection ││
│  └────────────────────────────────────────────────────────────────┘│
│                              │                                      │
│  ┌────────────────────────────────────────────────────────────────┐│
│  │  Downsample: Conv3×3(out_ch → out_ch, stride=2, padding=1)    ││
│  │  Learnable downsampling (better than MaxPool)                  ││
│  │  Shape: (B, out_ch, H/2, W/2)                                  ││
│  └────────────────────────────────────────────────────────────────┘│
│                                                                      │
│  Outputs:                                                           │
│    - features: (B, out_ch, H, W)     [for skip connection]         │
│    - downsampled: (B, out_ch, H/2, W/2)  [to next encoder level]   │
└──────────────────────────────────────────────────────────────────────┘
```

## Decoder Block Details

```
┌──────────────────────────────────────────────────────────────────────┐
│  DecoderBlock = Upsample + CBAM Attention + ResidualConvBlock       │
│                                                                      │
│  Inputs:                                                             │
│    - x: (B, in_ch, H, W)          [from previous decoder level]     │
│    - skip: (B, in_ch/2, H*2, W*2) [from encoder skip connection]    │
│                                                                      │
│  ┌────────────────────────────────────────────────────────────────┐│
│  │  Step 1: Upsample                                              ││
│  │  TransposeConv2d(in_ch → out_ch, kernel=2, stride=2)           ││
│  │  Shape: (B, out_ch, H*2, W*2)                                  ││
│  └──────────────────────────┬─────────────────────────────────────┘│
│                             │                                       │
│  ┌──────────────────────────▼─────────────────────────────────────┐│
│  │  Step 2: CBAM Attention on Skip Connection                     ││
│  │  ┌──────────────────────────────────────────────────────────┐ ││
│  │  │  CBAM(skip)                                              │ ││
│  │  │  ┌────────────────────────────────────────────────────┐ │ ││
│  │  │  │  Channel Attention Module:                         │ │ ││
│  │  │  │  1. GlobalAvgPool + GlobalMaxPool                  │ │ ││
│  │  │  │  2. Shared MLP: C → C/16 → C                       │ │ ││
│  │  │  │  3. Sigmoid → channel weights                      │ │ ││
│  │  │  │  4. Multiply with input                            │ │ ││
│  │  │  ├────────────────────────────────────────────────────┤ │ ││
│  │  │  │  Spatial Attention Module:                         │ │ ││
│  │  │  │  1. ChannelAvgPool + ChannelMaxPool → (B, 2, H, W)│ │ ││
│  │  │  │  2. Conv7×7 → (B, 1, H, W)                         │ │ ││
│  │  │  │  3. Sigmoid → spatial weights                      │ │ ││
│  │  │  │  4. Multiply with input                            │ │ ││
│  │  │  └────────────────────────────────────────────────────┘ │ ││
│  │  │  Output: skip_attended (B, out_ch, H*2, W*2)           │ ││
│  │  └──────────────────────────────────────────────────────────┘ ││
│  └──────────────────────────┬─────────────────────────────────────┘│
│                             │                                       │
│  ┌──────────────────────────▼─────────────────────────────────────┐│
│  │  Step 3: Concatenate                                           ││
│  │  cat([upsampled, skip_attended], dim=1)                        ││
│  │  Shape: (B, out_ch*2, H*2, W*2)                                ││
│  └──────────────────────────┬─────────────────────────────────────┘│
│                             │                                       │
│  ┌──────────────────────────▼─────────────────────────────────────┐│
│  │  Step 4: Residual Convolution                                  ││
│  │  ResidualConvBlock(out_ch*2 → out_ch, dropout)                 ││
│  │  Shape: (B, out_ch, H*2, W*2)                                  ││
│  └────────────────────────────────────────────────────────────────┘│
│                             │                                       │
│  Output: (B, out_ch, H*2, W*2)                                      │
└──────────────────────────────────────────────────────────────────────┘
```

## Adaptive Masked Transformer

```
┌──────────────────────────────────────────────────────────────────────────┐
│  Adaptive Masked Transformer (AMT)                                       │
│  Inspired by Vision Transformer with dynamic attention masking           │
│                                                                          │
│  Input: x (B, dim, H, W)  [e.g., (B, 512, 16, 16)]                      │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐│
│  │  Step 1: Patch Embedding                                           ││
│  │  ┌──────────────────────────────────────────────────────────────┐ ││
│  │  │  Divide into patches: (H, W) → (H/patch_size, W/patch_size)  │ ││
│  │  │  Example: 16×16 with patch_size=8 → 2×2 = 4 patches          │ ││
│  │  │  Actually uses Conv2d(dim, dim, kernel=patch_size, stride=patch_size) ││
│  │  │  Reshape: (B, dim, H/P, W/P) → (B, N, dim) where N=H*W/P²    │ ││
│  │  │  Output: (B, 256, 512)  [for H=W=16, P=8]                    │ ││
│  │  └──────────────────────────────────────────────────────────────┘ ││
│  └──────────────────────────┬─────────────────────────────────────────┘│
│                             │                                           │
│  ┌──────────────────────────▼─────────────────────────────────────────┐│
│  │  Step 2: Positional Encoding (Learnable)                           ││
│  │  pos_embed = nn.Parameter(torch.randn(1, N, dim))                  ││
│  │  x = x + pos_embed                                                 ││
│  └──────────────────────────┬─────────────────────────────────────────┘│
│                             │                                           │
│  ┌──────────────────────────▼─────────────────────────────────────────┐│
│  │  Step 3: Transformer Encoder Layers (×depth)                       ││
│  │  ┌──────────────────────────────────────────────────────────────┐ ││
│  │  │  Layer i (repeated depth=4 times):                           │ ││
│  │  │                                                               │ ││
│  │  │  ┌────────────────────────────────────────────────────────┐ │ ││
│  │  │  │  Multi-Head Self-Attention (MHSA)                      │ │ ││
│  │  │  │                                                         │ │ ││
│  │  │  │  Input: x (B, N, dim)                                  │ │ ││
│  │  │  │                                                         │ │ ││
│  │  │  │  1. Project to Q, K, V:                                │ │ ││
│  │  │  │     Q = Linear(dim, dim)(x)                            │ │ ││
│  │  │  │     K = Linear(dim, dim)(x)                            │ │ ││
│  │  │  │     V = Linear(dim, dim)(x)                            │ │ ││
│  │  │  │     Each: (B, N, dim) → (B, N, n_heads, dim/n_heads)  │ │ ││
│  │  │  │                                                         │ │ ││
│  │  │  │  2. Compute Attention Scores:                          │ │ ││
│  │  │  │     scores = Q @ K^T / sqrt(dim/n_heads)               │ │ ││
│  │  │  │     Shape: (B, n_heads, N, N)                          │ │ ││
│  │  │  │                                                         │ │ ││
│  │  │  │  3. Adaptive Masking (INNOVATION):                     │ │ ││
│  │  │  │     ┌───────────────────────────────────────────────┐ │ │ ││
│  │  │  │     │  Lightweight MLP predicts importance scores:  │ │ │ ││
│  │  │  │     │  importance = MLP(x)  # (B, N, 1)             │ │ │ ││
│  │  │  │     │  mask = Sigmoid(importance)  # (B, N, 1)      │ │ │ ││
│  │  │  │     │  scores = scores * mask.unsqueeze(-1)         │ │ │ ││
│  │  │  │     │  Focus attention on important regions         │ │ │ ││
│  │  │  │     └───────────────────────────────────────────────┘ │ │ ││
│  │  │  │                                                         │ │ ││
│  │  │  │  4. Softmax + Apply to V:                              │ │ ││
│  │  │  │     attn_weights = Softmax(scores)                     │ │ ││
│  │  │  │     out = attn_weights @ V                             │ │ ││
│  │  │  │     Shape: (B, n_heads, N, dim/n_heads)                │ │ ││
│  │  │  │                                                         │ │ ││
│  │  │  │  5. Concat heads + Project:                            │ │ ││
│  │  │  │     out = Concat(heads) @ W_o                          │ │ ││
│  │  │  │     Shape: (B, N, dim)                                 │ │ ││
│  │  │  └─────────────────────────────────────────────────────────┘ │ ││
│  │  │                             │                                │ ││
│  │  │  ┌─────────────────────────▼───────────────────────────────┐ │ ││
│  │  │  │  Residual + Layer Norm                                  │ │ ││
│  │  │  │  x = LayerNorm(x + MHSA_out)                            │ │ ││
│  │  │  └─────────────────────────┬───────────────────────────────┘ │ ││
│  │  │                             │                                │ ││
│  │  │  ┌─────────────────────────▼───────────────────────────────┐ │ ││
│  │  │  │  Feed-Forward Network (MLP)                             │ │ ││
│  │  │  │  ┌────────────────────────────────────────────────────┐ │ │ ││
│  │  │  │  │  Linear(dim, dim*4)  # 512 → 2048                  │ │ │ ││
│  │  │  │  │  GELU activation                                    │ │ │ ││
│  │  │  │  │  Linear(dim*4, dim)  # 2048 → 512                  │ │ │ ││
│  │  │  │  │  Dropout(0.1)                                       │ │ │ ││
│  │  │  │  └────────────────────────────────────────────────────┘ │ │ ││
│  │  │  └─────────────────────────┬───────────────────────────────┘ │ ││
│  │  │                             │                                │ ││
│  │  │  ┌─────────────────────────▼───────────────────────────────┐ │ ││
│  │  │  │  Residual + Layer Norm                                  │ │ ││
│  │  │  │  x = LayerNorm(x + MLP_out)                             │ │ ││
│  │  │  └─────────────────────────────────────────────────────────┘ │ ││
│  │  └──────────────────────────────────────────────────────────────┘ ││
│  └──────────────────────────┬─────────────────────────────────────────┘│
│                             │                                           │
│  ┌──────────────────────────▼─────────────────────────────────────────┐│
│  │  Step 4: Reshape back to spatial                                   ││
│  │  (B, N, dim) → (B, dim, H/P, W/P)                                  ││
│  │  Example: (B, 256, 512) → (B, 512, 2, 2)                           ││
│  └────────────────────────────────────────────────────────────────────┘│
│                                                                          │
│  Output: (B, dim, H/P, W/P)  [e.g., (B, 512, 2, 2)]                    │
│  Then upsampled by TransposeConv to (B, dim_out, H, W)                 │
└──────────────────────────────────────────────────────────────────────────┘
```

## Multi-Scale Fusion

```
┌──────────────────────────────────────────────────────────────────────────┐
│  Multi-Scale Fusion Module                                               │
│  Combines features from all decoder levels for richer representation     │
│                                                                          │
│  Inputs (from 4 decoder levels):                                         │
│    d1: (B, 48, 256, 256)   ← Finest resolution                          │
│    d2: (B, 96, 128, 128)   ← Medium-fine                                │
│    d3: (B, 192, 64, 64)    ← Medium-coarse                              │
│    d4: (B, 384, 32, 32)    ← Coarsest                                   │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐│
│  │  Step 1: Channel Projection (to common dimension = 48)             ││
│  │  ┌──────────────────────────────────────────────────────────────┐ ││
│  │  │  d1_proj = Conv1×1(48 → 48)(d1)    → (B, 48, 256, 256)       │ ││
│  │  │  d2_proj = Conv1×1(96 → 48)(d2)    → (B, 48, 128, 128)       │ ││
│  │  │  d3_proj = Conv1×1(192 → 48)(d3)   → (B, 48, 64, 64)         │ ││
│  │  │  d4_proj = Conv1×1(384 → 48)(d4)   → (B, 48, 32, 32)         │ ││
│  │  └──────────────────────────────────────────────────────────────┘ ││
│  └──────────────────────────┬─────────────────────────────────────────┘│
│                             │                                           │
│  ┌──────────────────────────▼─────────────────────────────────────────┐│
│  │  Step 2: Spatial Upsampling (to target size = 256×256)             ││
│  │  ┌──────────────────────────────────────────────────────────────┐ ││
│  │  │  target_size = d1.shape[-2:]  # (256, 256)                   │ ││
│  │  │                                                               │ ││
│  │  │  d1_up = d1_proj  # Already 256×256                          │ ││
│  │  │  d2_up = F.interpolate(d2_proj, size=256, mode='bilinear')   │ ││
│  │  │          → (B, 48, 256, 256)                                 │ ││
│  │  │  d3_up = F.interpolate(d3_proj, size=256, mode='bilinear')   │ ││
│  │  │          → (B, 48, 256, 256)                                 │ ││
│  │  │  d4_up = F.interpolate(d4_proj, size=256, mode='bilinear')   │ ││
│  │  │          → (B, 48, 256, 256)                                 │ ││
│  │  └──────────────────────────────────────────────────────────────┘ ││
│  └──────────────────────────┬─────────────────────────────────────────┘│
│                             │                                           │
│  ┌──────────────────────────▼─────────────────────────────────────────┐│
│  │  Step 3: Fusion by Element-wise Summation                          ││
│  │  ┌──────────────────────────────────────────────────────────────┐ ││
│  │  │  fused = d1_up + d2_up + d3_up + d4_up                       │ ││
│  │  │  Shape: (B, 48, 256, 256)                                    │ ││
│  │  │                                                               │ ││
│  │  │  # Normalize and activate                                    │ ││
│  │  │  fused = InstanceNorm2d(fused)                               │ ││
│  │  │  fused = LeakyReLU(fused)                                    │ ││
│  │  └──────────────────────────────────────────────────────────────┘ ││
│  └──────────────────────────┬─────────────────────────────────────────┘│
│                             │                                           │
│  ┌──────────────────────────▼─────────────────────────────────────────┐│
│  │  Step 4: Combine with final decoder output                         ││
│  │  ┌──────────────────────────────────────────────────────────────┐ ││
│  │  │  combined = torch.cat([d1, fused], dim=1)                    │ ││
│  │  │  Shape: (B, 96, 256, 256)  # 48 + 48 = 96                    │ ││
│  │  │                                                               │ ││
│  │  │  final = ResidualConvBlock(96 → 48)                          │ ││
│  │  │  Shape: (B, 48, 256, 256)                                    │ ││
│  │  └──────────────────────────────────────────────────────────────┘ ││
│  └────────────────────────────────────────────────────────────────────┘│
│                             │                                           │
│  Output: (B, 48, 256, 256)                                              │
│  Rich multi-scale features combining fine & coarse information          │
└──────────────────────────────────────────────────────────────────────────┘

Why Multi-Scale Fusion?
  - Fine features (d1): Good for boundaries and details
  - Coarse features (d4): Good for global context and large structures
  - Combining all: Best of both worlds → Better segmentation accuracy
```

## Classification Branch

```
┌──────────────────────────────────────────────────────────────────────────┐
│  T-InceptionNet: Classification with ROI Gating                          │
│                                                                          │
│  Inputs:                                                                 │
│    - original_input: (B, 4, 256, 256)  [Multi-modal MRI]                │
│    - seg_logits: (B, 3, 256, 256)      [From segmentation branch]       │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐│
│  │  Step 1: ROI Gating (Whole Tumor Probability)                      ││
│  │  ┌──────────────────────────────────────────────────────────────┐ ││
│  │  │  # Compute whole tumor probability                           │ ││
│  │  │  seg_prob = Softmax(seg_logits, dim=1)                       │ ││
│  │  │  # (B, 3, 256, 256) with probs for [bg, TC, ED]              │ ││
│  │  │                                                               │ ││
│  │  │  # Whole Tumor = TC (class 1) + ED (class 2)                 │ ││
│  │  │  wt_prob = seg_prob[:, 1:, :, :].sum(dim=1, keepdim=True)    │ ││
│  │  │  # Shape: (B, 1, 256, 256)                                   │ ││
│  │  │                                                               │ ││
│  │  │  # Reduce multi-modal to single channel                      │ ││
│  │  │  roi_input = Conv2d(4 → 1, bias=False)(original_input)       │ ││
│  │  │  # Shape: (B, 1, 256, 256)                                   │ ││
│  │  │                                                               │ ││
│  │  │  # Apply ROI mask (stop gradient!)                           │ ││
│  │  │  roi = roi_input * wt_prob.detach()                          │ ││
│  │  │  # Shape: (B, 1, 256, 256)                                   │ ││
│  │  │  # .detach() prevents gradient flow to segmentation          │ ││
│  │  └──────────────────────────────────────────────────────────────┘ ││
│  └──────────────────────────┬─────────────────────────────────────────┘│
│                             │                                           │
│  ┌──────────────────────────▼─────────────────────────────────────────┐│
│  │  Step 2: T-Inception Blocks (×3 or 4)                              ││
│  │  ┌──────────────────────────────────────────────────────────────┐ ││
│  │  │  T-InceptionBlock (Multi-scale parallel convolutions)        │ ││
│  │  │                                                               │ ││
│  │  │  Input: (B, in_ch, H, W)                                     │ ││
│  │  │                                                               │ ││
│  │  │  ┌────────────────────────────────────────────────────────┐ │ ││
│  │  │  │  Branch 1: Conv1×1(in_ch → out_ch/4)                   │ │ ││
│  │  │  │  Point-wise features                                    │ │ ││
│  │  │  └────────────────────────────────────────────────────────┘ │ ││
│  │  │  ┌────────────────────────────────────────────────────────┐ │ ││
│  │  │  │  Branch 2: Conv3×3(in_ch → out_ch/4, padding=1)        │ │ ││
│  │  │  │  Local spatial features                                 │ │ ││
│  │  │  └────────────────────────────────────────────────────────┘ │ ││
│  │  │  ┌────────────────────────────────────────────────────────┐ │ ││
│  │  │  │  Branch 3: Conv1×3(in_ch → out_ch/4, padding=(0,1))    │ │ ││
│  │  │  │  Horizontal features                                    │ │ ││
│  │  │  └────────────────────────────────────────────────────────┘ │ ││
│  │  │  ┌────────────────────────────────────────────────────────┐ │ ││
│  │  │  │  Branch 4: Conv3×1(in_ch → out_ch/4, padding=(1,0))    │ │ ││
│  │  │  │  Vertical features                                      │ │ ││
│  │  │  └────────────────────────────────────────────────────────┘ │ ││
│  │  │                                                               │ ││
│  │  │  Concatenate: [b1, b2, b3, b4] along channel dimension       │ ││
│  │  │  Output: (B, out_ch, H, W)                                   │ ││
│  │  └──────────────────────────────────────────────────────────────┘ ││
│  │                                                                    ││
│  │  # Repeat 3-4 times with downsampling between blocks              ││
│  │  Block1: (B, 1, 256, 256) → (B, 64, 128, 128)                     ││
│  │  Block2: (B, 64, 128, 128) → (B, 128, 64, 64)                     ││
│  │  Block3: (B, 128, 64, 64) → (B, 256, 32, 32)                      ││
│  │  Block4: (B, 256, 32, 32) → (B, 512, 16, 16)                      ││
│  └──────────────────────────┬─────────────────────────────────────────┘│
│                             │                                           │
│  ┌──────────────────────────▼─────────────────────────────────────────┐│
│  │  Step 3: Classification Head                                        ││
│  │  ┌──────────────────────────────────────────────────────────────┐ ││
│  │  │  # Global pooling                                            │ ││
│  │  │  pooled = AdaptiveAvgPool2d((1, 1))(features)                │ ││
│  │  │  # Shape: (B, 512, 1, 1) → (B, 512)                          │ ││
│  │  │                                                               │ ││
│  │  │  # Fully connected layers                                    │ ││
│  │  │  fc1 = Linear(512 → 256)(pooled)                             │ ││
│  │  │  relu1 = ReLU(fc1)                                           │ ││
│  │  │  drop = Dropout(0.5)(relu1)                                  │ ││
│  │  │  fc2 = Linear(256 → num_classes)(drop)                       │ ││
│  │  │  # num_classes = 2 for [HGG, LGG]                            │ ││
│  │  │                                                               │ ││
│  │  │  cls_logits = fc2  # (B, 2)                                  │ ││
│  │  └──────────────────────────────────────────────────────────────┘ ││
│  └────────────────────────────────────────────────────────────────────┘│
│                             │                                           │
│  Output: cls_logits (B, 2)  [HGG vs LGG logits]                         │
└──────────────────────────────────────────────────────────────────────────┘
```

## 🔢 Numerical Flow (Early Training Example)

```
INPUT: Logits (B, 3, 256, 256), Target (B, 256, 256)
   │
   ├─→ Dice Loss
   │      ├─→ TC: Dice=0.25 → Loss=0.75 → Weighted=0.75×4.0=3.0
   │      └─→ ED: Dice=0.35 → Loss=0.65 → Weighted=0.65×2.5=1.625
   │      └─→ Mean = (3.0 + 1.625)/2 = 2.3125
   │
   ├─→ Focal Loss
   │      ├─→ Hard examples (low confidence): Loss ≈ 2.0
   │      └─→ (BG ignored with alpha=0.0)
   │
   ├─→ IoU Loss (✅ FIXED!)
   │      ├─→ TC: IoU=0.20 → Loss=0.80 → Weighted=0.80×4.0=3.2
   │      └─→ ED: IoU=0.30 → Loss=0.70 → Weighted=0.70×2.5=1.75
   │      └─→ Mean = (3.2 + 1.75)/2 = 2.475
   │
   └─→ Boundary Loss
          └─→ Edge errors: ≈ 3.5

MainSegLoss = 1.0×2.3125 + 1.0×2.0 + 2.5×2.475 + 0.6×3.5
            = 2.3125 + 2.0 + 6.1875 + 2.1
            = 12.6

With AuxLoss (3 auxiliary outputs):
SegLoss = 12.6 + 0.3×(similar)×3 ≈ 23.4

ClassificationLoss = -log(0.8) ≈ 0.22

TOTAL = 23.4 + 0.5×0.22 = 23.51 ✅ POSITIVE
```
